# Gallery images

Drop workshop and event photographs into this folder (`.jpg`, `.jpeg`, `.png`,
`.webp`, `.gif`, `.avif`, or `.svg`). Every image here automatically appears on
the Gallery page the next time the site is deployed.

Tips:

- Use descriptive file names — `spss-workshop-nirma-university.jpg` becomes the
  caption "Spss Workshop Nirma University".
- Landscape photos around 1200×900 px look best; keep files under ~500 KB.
